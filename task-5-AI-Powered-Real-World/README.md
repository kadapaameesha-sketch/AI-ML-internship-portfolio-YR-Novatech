# Task 5: AI-Powered Real-World Application (Predictive Web App)

## Overview
A complete machine learning web application built using Python and Streamlit that solves a practical real-world problem by taking user inputs, processing them through a trained ML model, and generating real-time predictions.

## Features
- **User Input Interface:** Interactive UI elements to input custom parameters.
- **Data Processing Pipeline:** Real-time feature scaling and model inference.
- **AI-Powered Prediction:** Outputs instantaneous, data-driven predictions.

## Technologies Used
- Python
- Streamlit / Scikit-Learn
- Pandas & NumPy

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `streamlit run app.py`
