# Task 3: AI Hand Gesture Recognition

## Overview
A real-time computer vision application built using Python, OpenCV, and MediaPipe to detect and classify human hand gestures via webcam input.

## Features
* Detects hands using machine learning landmark estimation.
* Recognizes four target gestures: **Open Hand**, **Fist**, **Thumbs Up**, and **Victory/Peace**.
* Displays real-time visual labels and hand skeletons on screen.

## Technologies Used
* **Python**
* **OpenCV** (for image processing and display)
* **MediaPipe** (for high-accuracy hand landmark tracking)
